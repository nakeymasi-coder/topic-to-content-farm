🦋 Welcome to your Topic-to-Content Farm

Give it a topic. It does the rest. One dashboard holds your Topic Intake Form, your Character Vault for locked characters, your Prompt Library for prompts you save and reuse, solo forms for each of your 5 agents, and a Queue for your runs.

You type one topic. Your AI assistant works as the 5 agents, in order, in your chat - Scout, Image, Story, Video, Caption - and returns every finished piece to you in chat for your approval.

Use a solo form when you want just one agent job by itself. Use the full Topic Intake Form when you want a complete run, all 5 agents in order, from one topic.

How Run in Chat works

  1. Fill in the Topic Intake Form, or a solo agent form, and add it to the Queue.
  2. Open the Queue and tap Run in Chat on that run. That sets the run to working and opens its Run in Chat card.
  3. Tap Copy Prompt on the Run in Chat card and paste it into chat with your AI assistant.
  4. Your AI runs that exact run in chat - nothing swapped - starting from the topic and your Prompt Library, and brings the finished pieces back to you in chat for your approval.
  5. Back here, set the status yourself when you are ready: queued, working, or done. The status button only changes the label - it never executes anything. Execution happens in chat.

There is no scheduled pickup. Nothing runs on its own and nothing is posted automatically.

Library First - your prompts, reused

Every run starts from the topic, and the Prompt Scout searches your Prompt Library first for a fitting prompt before writing anything new. Your library holds your own prompts, prompts the Scout writes for you, and prompts from any prompt library you belong to.

Any prompt a run creates or cleans gets saved back to your Prompt Library, named and categorized, so your library grows with every run and the next run reuses it.

The 5 Agents - in this order

Agent 1 - Prompt Scout

Starts from the TOPIC. Searches your Prompt Library first for a fitting prompt. If the run needs an outfit or product the prompt does not cover, it also searches Pinterest in guest view (no sign-in), especially products with an Amazon link, and copies the picture. If nothing fits, it says so plainly and writes a fresh prompt for the topic in your style - and saves it to your Prompt Library so the next run reuses it.

Agent 2 - Image Agent

Creates the person and avatar images in chat from the prompt - character references, the outfit photo (your locked character wearing the exact outfit), and the outfit reference sheet. All ultra realistic, real skin and hair texture, all PNG, all 9:16 for video and character work; a prompt that states its own shape keeps it.

Agent 3 - Story Agent

Writes the hook, the shots, and the script from the topic. Labels every scene with the run's one Product Presentation choice. Writes scene ACTION only for video prompts - never a description of the character.

Agent 4 - Video Agent

Makes the video in chat with your AI video tool, using the Consistent Character workflow on this page. Returns the finished video in chat for your approval. Never posts it.

Agent 5 - Caption Agent

Writes the caption, the on-screen hook, and the hashtags for the platform on the run. No price, discount, or sale claim unless a live price was actually verified. Also saves any prompt the run created or cleaned into your Prompt Library, named and categorized.

The 7 Modes

A mode is a setting, not a separate farm. It changes the search, the story structure, the shots, and the captions.

1. Full Content Run 2. Image Only Run 3. Typography Run 4. Product Design Run 5. Get Ready With Me 6. Product Review 7. Prompt Only Run

Full Content Run: topic to finished video - Scout, Image, Story, Video, Caption, in order, returned in chat for your approval. Image Only Run: topic to finished images (portraits, designs, product shots), no video. Typography Run: topic to finished lettering art, PNG. Product Design Run: topic to a finished design shown on a mock-up. Get Ready With Me: the classic GRWM structure, built from the topic. Product Review: the classic review structure, wearing OR holding per the run's one choice. Prompt Only Run: the Scout finds or writes the prompt for the topic, cleans it, saves it to your Prompt Library, and hands it back ready to copy.

Product Presentation - one choice, never both

Runs with a product pick one single choice, right after Mode: Wearing the product OR Holding the product. Never both. No product? The run stays on No product and no wearing or holding line is added.

Wearing run: every prompt ends with this exact sentence: "Wearing the product, not holding it."

Holding run: every prompt ends with this exact sentence: "Holding the product, not wearing it."

Never show her wearing an outfit while holding that same outfit on a hanger. Reject and regenerate any image that shows both. If a video needs both, use separate scenes - holding first, wearing later - never the same shot.

That one choice is saved on the run and shown on the Queue card and the Run in Chat card, with its exact prompt sentence.

The Workflow - written into every run prompt

  1. TOPIC FIRST. Everything serves the topic on the run. If no topic was given, the AI asks for one - one line, nothing else.
  2. SCOUT: search your Prompt Library for a fitting prompt. If an outfit or product beyond the prompt is needed, pick it on Pinterest in guest view (one with an Amazon link when there is a product) and copy its picture. If nothing fits, the prompt is written fresh in your style, and the AI says so plainly.
  3. LOCK THE OUTFIT IN CHAT, not in the video tool: using your locked character's reference photos, the AI puts that character in that exact outfit in chat first. Face match and outfit match get checked.
  4. MAKE THE OUTFIT REFERENCE SHEET IN CHAT: from the approved outfit photo, one single 9:16 sheet with front, profile, and three-quarter shots of her in that outfit, all on the same photo. Saved as PNG.
  5. BUILD WITH THE CONSISTENT CHARACTER LOCK: Reference One is her headshot (Slot 1). Reference Two is the chat-made outfit reference sheet. NEVER leave Reference Two empty. The reference photos ARE the lock - no descriptions of her go into scene prompts.
  6. STORY: hook, shots, script - scene ACTION only, every scene labeled with the run's one Product Presentation choice.
  7. VIDEO: the scenes are created from that lock, in script order, 9:16.
  8. CAPTION: caption, on-screen hook, hashtags for the run's platform. No price or sale claim unless a live price was verified.
  9. SAVE THE PROMPT: any prompt created or cleaned goes into your Prompt Library with a name and category, so the library grows with every run.
  10. RETURN EVERYTHING IN CHAT for your approval. Nothing is ever posted, published, or shared.

The Scene Prompt Shape - use this, and nothing else about her

"Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it."

For a Holding run, the last sentence swaps to: "Holding the product, not wearing it."

NEVER describe her in a scene prompt - no face, hair, skin, body, or outfit description. Describing her overrides the references and creates a different person.

Character lock rules

  • Your characters are ultra realistic, with real skin texture and real hair texture. Plus-size stays plus-size, never slimmed down.
  • Slot 1 is one headshot photo, 9:16. Slot 2 is ONE single 9:16 body reference sheet - front, three-quarter, left profile, and right side views of the same person, same outfit, same background, all on that one photo. Not separate photos.
  • A character is NOT locked until BOTH slots are filled.
  • Within one video, identity, clothing, location, and lighting stay frozen from the reference photos.
  • Your uploads are accepted as JPG or PNG, as you saved them. This dashboard never forces your uploads to PNG. If you upload a webp, it is rejected with a clear message: "JPG or PNG please."

Standing rules

  • Every image your AI creates is PNG, never webp. Your own uploads stay as you saved them (JPG or PNG).
  • Nothing is posted automatically, ever. Posting always needs your separate approval.
  • No price, discount, or sale claim in any caption or copy unless a live price was actually verified.
  • Voice and copy everywhere: personable, human, plain words. No em dashes - use hyphens instead.
  • Your characters, Prompt Library, and runs save in this browser on this device. Use Export Backup on the Queue page to keep a copy you can bring back with Import Backup.
